# 8-Bit-ALU-Design

8-bit ALU design using Verilog HDL with simulation and testbench.

## Features
- Addition
- Subtraction
- AND
- OR
- XOR
- Shift Operations

## Verilog Code
Code files are available in the `verilog_code` folder.
